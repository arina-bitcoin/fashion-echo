# Fashion-eco

Fashion Echo — это сайт для покупки, продажи и обмена использованной одежды или одежды с дефектами. На сайте реализован поиск секондхендов, возможность продавать и покупать вещи

Идеология:
- Экология: максимальное использование вещей — отсутствие перепроизводства
- Благотворительность: удешевлённые вещи для всех: в том числе малоимущих
- Вторая жизнь для вещей пользователя
- Простота сервиса
- Самостоятельность сервиса: минимальная поддержка

Функционал mvp:
Пользователь регистрируется по почте, этап регистрации можно пропустить до покупки первого товара

Виды объявлений:
- Продажа
- Обмен
- Предложение покупки

На сайте видит 5 разделов:
1) Главная
    - Информация о проекте, нашей идеологии
    - Ссылки на другие разделы
2) Поиск секондхендов по адресам, названиям, можно переключиться на карту (API Яндекс карты)
3) Объявления: поиск по выложенным объявлениям
4) Мои объявления: поиск по моим объявлениям, возможность редактирования
5) Профиль
    - Информация о пользователе
    - Настройки внешнего вида сайта, уведомлений
    - Инструкция по использованию сайта

Функционал (возможный) — после mvp:
- Продавец может ставить метки в объявлении:
1) Для всех пользователей
2) Для малоимущих

- 2 роли для регистрации:
1) Малоимущий покупатель — им будут доступны объявления с пометкой "для малоимущих" — нужна проверка документов/синхронизация с госуслугами
2) Обычный продавец/покупатель

- Ограничение максимальной стоимости товара "для малоимущих"
- Модерация объявлений
- Рекомендательная система
- Платежная система

Функции:
- Выставление объявлений: о продаже, потенциальной покупке, обмене
- Поиск по секонд хендам (в том числе в виде карты): все собраны в одном месте
- Просмотр объявлений — БЕЗ возможности покупки

Преимущество перед конкурентами:
авито, юла — любой сервис покупки б/у товаров:
- сервисы не предлагают льгот для малоимущих
- выставление объявлений на них платное (авито) — надо прикреплять карту
- коммисия с продажи
- избыточный функционал для людей, ищущих вещи дёшево или бесплатно
