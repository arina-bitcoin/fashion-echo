## 🏗️ Архитектура приложения

### Компоненты системы

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│     Client      │────│    Frontend     │────│    Backend      │
│   (Browser)     │    │   (Port 3000)   │    │  (Port 8000)    │
└─────────────────┘    └─────────────────┘    └─────────────────┘
                                                       │
                                               ┌─────────────────┐
                                               │   PostgreSQL    │
                                               │   (Port 5432)   │
                                               └─────────────────┘
```

### Сети и изоляция

- **fashion-eco-network**: Основная сеть для frontend/backend коммуникации
- **db-network**: Изолированная внутренняя сеть для баз данных (без доступа в интернет)

### Persistent Storage

- **postgres-data**: Данные PostgreSQL
- **app-media**: Загруженные пользователями файлы
- **app-logs**: Логи приложения
- **file-storage**: Файловое хранилище приложения

## 🐳 Docker Образы

### Размеры образов

| Образ | Размер | Оптимизация |
|-------|--------|-------------|
| **fashion__eco-frontend** | **93.3MB** | Multi-stage build + Alpine + минификация |
| **fashion__eco-backend** | **372MB** | Multi-stage build + Python slim |

### Multi-stage оптимизации

**Frontend:**
1. **Этап сборки**: Node.js Alpine для минификации CSS/JS
2. **Финальный этап**: Nginx Alpine с оптимизированными статическими файлами

**Backend:**
1. **Этап сборки**: Python slim + build tools для установки зависимостей
2. **Финальный этап**: Python slim + только runtime зависимости

## 🔐 Безопасность

### Непривилегированные пользователи

- **Backend**: Пользователь `appuser` (UID: 1001)
- **Frontend**: Пользователь `nginx-user` (UID: 1001)
- **Все контейнеры** запускаются без root привилегий

### Сетевая изоляция

- База данных в изолированной внутренней сети
- Только необходимые порты экспонированы
- CORS настроен для разрешенных доменов

## 📊 Health Checks

Все сервисы имеют настроенные health checks:

```yaml
# PostgreSQL
healthcheck:
  test: ["CMD-SHELL", "pg_isready -U fashion_user -d fashion_eco"]
  interval: 30s
  timeout: 10s
  retries: 5

# Backend
healthcheck:
  test: ["CMD", "curl", "-f", "http://localhost:8000/health"]
  interval: 30s
  timeout: 10s
  retries: 3

# Frontend
healthcheck:
  test: ["CMD", "wget", "--spider", "http://localhost:80/health"]
  interval: 30s
  timeout: 10s
  retries: 3
```

## 🚀 Команды для запуска

### Production

```bash
# Клонирование и настройка
git clone <repository-url>
cd fashion-eco
cp .env.example .env
# Отредактировать .env файл

# Запуск
docker-compose up -d

# Проверка
curl http://localhost/health
```

### Development

```bash
# Запуск в dev режиме
docker-compose -f docker-compose.dev.yml up -d

# С дополнительными инструментами
docker-compose -f docker-compose.dev.yml --profile dev-tools up -d
```

### Тестирование

```bash
# Unit тесты
docker-compose -f docker-compose.test.yml up --abort-on-container-exit

# Нагрузочное тестирование
docker-compose -f docker-compose.test.yml --profile load-test up
```
