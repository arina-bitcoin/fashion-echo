# Структура хранения файлов

## Унифицированная структура в `file_storage/`

Все файлы теперь хранятся в единой папке `file_storage/` со следующей структурой:

```
file_storage/
├── images/
│   ├── avatars/          # Аватары пользователей
│   └── ads/              # Изображения объявлений
├── documents/            # Документы (если потребуются)
└── temp/                 # Временные файлы
```

## Доступ к файлам

Все файлы доступны через единую точку входа:
- **URL**: `http://localhost:8000/static/`
- **Примеры**:
  - Аватар: `http://localhost:8000/static/images/avatars/filename.jpg`
  - Изображение объявления: `http://localhost:8000/static/images/ads/filename.jpg`

## Преимущества новой структуры

1. **Единая точка доступа**: все файлы через `/static/`
2. **Упрощенная конфигурация**: один mount point в FastAPI
3. **Консистентность**: все файлы в одном месте
4. **Безопасность**: единые правила доступа
5. **Резервное копирование**: одна папка для бэкапа
6. **Логическая организация**: четкая иерархия папок
